Disclosures

  • The Treason-API (TAPI) has never, and will never, use generative AI to add functionality to its codebase.
  • All code is human-written and created with both passion and patience.

    That being said, GitHub Copilot is (sparingly) used for creating verbose commit messages. The process of compiling and testing TAPI without surrounding it with junk is simply too slow to edit directly in the cloned repository directory. Therefore, large sets of changes are often committed to the repository and require proper documentation rather than a lazy meaningless message. This is why a few commit messages are written by GitHub Copilot. The changes made to code within these commits are still 100% human-created.

Public Statement

Programming, coding, scripting... are all forms of creative expression. In the context of adding custom content to a video game through modification, there is no welcoming room for AI-generated content. The Treason-API (TAPI) was created to massively expand the realm of possibility for those who wish to add custom content to Klaus Veen's Treason (KVT)... Not for people who are unwilling to create their own art, let alone learn the means of creation.

That also being said, please take a moment to consider learning the process of creating SourceMod plugins for Treason before aimlessly copy-and-pasting back-and-forth with an AI model.

Knowledge is power, and the unwillingness to learn is weakness calling your name.
